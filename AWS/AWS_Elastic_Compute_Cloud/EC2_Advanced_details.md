| Setting                              | Recommended                          | Explanation                                                                                                                                                                             |
| ------------------------------------ | ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Domain join directory**            | **None** (unless required)           | Used to automatically join an EC2 instance to an AWS Managed Microsoft Active Directory or AD Connector. Required only for Windows domains or enterprise Active Directory environments. |
| **IAM instance profile**             | **Attach an IAM Role** ✅             | Always attach the least-privilege IAM role needed by the instance (for example, `AmazonSSMManagedInstanceCore` if using Systems Manager).                                               |
| **Hostname type**                    | **IP name** (default)                | Instance hostname is based on its private IP address. Use **DNS Hostname** only if your organisation requires hostname-based naming.                                                    |
| **DNS Hostname**                     | **Enable IPv4 A record**             | Allows the instance to receive a private DNS name. Leave resource-based DNS options at their defaults unless you specifically need them.                                                |
| **Instance auto-recovery**           | **Enable for production**            | AWS automatically recovers the instance to new hardware if the underlying host fails. Useful for critical workloads.                                                                    |
| **Shutdown behavior**                | **Stop**                             | Prevents accidental data loss. Selecting **Terminate** permanently deletes the instance when the OS shuts down.                                                                         |
| **Stop - Hibernate behavior**        | **Disabled** (unless required)       | Hibernate saves RAM contents to disk before stopping. Useful for long-running applications but requires additional configuration.                                                       |
| **Termination protection**           | **Enable for Production**            | Prevents accidental deletion of important EC2 instances.                                                                                                                                |
| **Stop protection**                  | Optional                             | Prevents accidental stopping of the instance. Useful for mission-critical servers.                                                                                                      |
| **Detailed CloudWatch monitoring**   | **Enable for Production**            | Sends metrics every **1 minute** instead of the default **5 minutes**, improving monitoring and auto scaling responsiveness. Additional charges apply.                                  |
| **Credit specification**             | **Unlimited** for T-series (t3, t4g) | Prevents CPU throttling by allowing burst performance. Additional charges apply if CPU credits are exceeded.                                                                            |
| **Placement group**                  | None (unless needed)                 | Used for high-performance computing or low-latency clustered applications. Not required for typical web servers.                                                                        |
| **EBS-optimized instance**           | **Enable**                           | Provides dedicated bandwidth between EC2 and EBS. Most modern instance types enable this by default.                                                                                    |
| **Instance bandwidth configuration** | Default                              | Leave unchanged unless AWS documentation recommends otherwise for your workload.                                                                                                        |
| **Purchasing option**                | **On-Demand** (None)                 | Suitable for learning and production. Spot Instances are cheaper but can be interrupted.                                                                                                |
| **Capacity reservation**             | None                                 | Reserve EC2 capacity for guaranteed availability. Used mainly in enterprise environments.                                                                                               |
| **Tenancy**                          | **Shared**                           | Default and most cost-effective. Dedicated tenancy is only needed for licensing or compliance requirements.                                                                             |
| **RAM disk ID**                      | None                                 | Legacy feature. Rarely used today.                                                                                                                                                      |
| **Kernel ID**                        | None                                 | Legacy feature used with paravirtual AMIs. Modern Nitro instances do not require it.                                                                                                    |
| **Nitro Enclave**                    | Disabled (unless required)           | Provides an isolated execution environment for highly sensitive applications such as cryptographic operations.                                                                          |
| **License configurations**           | None                                 | Used with AWS License Manager for BYOL (Bring Your Own License) scenarios.                                                                                                              |
| **CPU options**                      | **Use default CPU options**          | Only customise if you need to reduce vCPUs for software licensing or performance tuning.                                                                                                |
| **Nested virtualization**            | Not supported                        | Depends on the instance type. Ignore if unavailable.                                                                                                                                    |
| **Metadata accessible**              | **Enabled**                          | Required for IAM roles, Systems Manager, and other AWS services. Do not disable unless you have a specific reason.                                                                      |
| **Metadata IPv6 endpoint**           | Disabled                             | Enable only if your VPC uses IPv6.                                                                                                                                                      |
| **Metadata version**                 | **V2 only (token required)** ✅       | This is **IMDSv2**. Always choose this for better security.                                                                                                                             |
| **Metadata response hop limit**      | **2**                                | Default value. Increase only if containers or proxies legitimately need additional network hops.                                                                                        |
| **Allow tags in metadata**           | Disabled (recommended)               | Enable only if applications need to read EC2 tags through the metadata service.                                                                                                         |
| **User data**                        | Optional                             | Used to run scripts automatically when the instance boots for the first time (for example, install Nginx, Docker, or update packages).                                                  |
